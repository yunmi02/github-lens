# 安全与数据边界

## 身份和会话

首次设置从服务器本机完成，或在运行前配置 ADMIN_PASSWORD。管理员密码使用带盐 PBKDF2 哈希；登录尝试在哈希计算前占用并发安全的限速额度。

“偏好设置 → 账号安全”支持验证当前密码后修改密码，撤销其他设备的旧登录，并保持当前会话可用。管理员 Cookie 使用 HttpOnly 和 SameSite；HTTPS 公网部署应配置 COOKIE_SECURE=true。

## 图片与手机上传

上传在 multipart 解析前验证身份及批次归属。单图上限 20 MiB，实际请求体最多 21 MiB；不依赖客户端 Content-Length。仅接受 PNG、JPEG、WebP，并检查文件格式与像素上限。

二维码为一次领取的临时凭证，使用数据库条件更新确保并发时仅一个请求成功。手机凭证不能读取管理员资料库或其他批次；可在电脑端撤销。原图读取限制在上传目录，批次删除检查路径范围。

## 来源与模型

普通 OCR 在本机执行。图片理解与中文归纳会把截图、OCR 线索或保存的来源正文发送给配置的模型服务。请根据自己的资料和供应商条款选择服务，不在截图中包含不希望发送的信息。

浏览器研究使用独立 Chrome，仅读取允许的公开地址。图片、OCR 和网页不被视为操作指令。引用匹配不代表模型语义判断或项目创新性的独立认证。

## 密钥和备份

- 只提交 `.env.example`，不提交实际 `.env`、Token、管理员密码或私钥。
- `data/` 包含原图、数据库、登录签名密钥、报告与备份，按私有资料保存。
- GitHub Token 用于获取公开仓库资料；建议仅授予所需读取权限。
- 模型密钥和 GitHub Token 不回显到界面。修改配置前保留可靠备份，恢复时停止服务。
- 本地鉴权测试代理、个人运行记录、浏览器截图和开发机快照不属于源码发布内容。

## 依赖与部署

图像库最低版本为 Pillow 13，实际验证版本保存在 backend/requirements-tested.txt。精确版本快照不等于未来无漏洞，应持续复扫依赖公告。

当前部署为本机、单管理员、单 Worker。公网部署仍需配置 HTTPS、反向代理及网络访问边界；多租户和多实例部署不在当前支持范围。

项目的安全问题请通过仓库提供的私密报告渠道或与维护者私下沟通，避免在公开 Issue 中粘贴密钥、原图、数据库或可直接利用的敏感内容。
